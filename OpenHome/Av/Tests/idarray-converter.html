OpenHome IdArray ↔ JSON Converter

IdArray = stream of 4-byte big-endian unsigned integers. Left side is the wire encoding; right side is a JSON array of the track IDs.

 

Each ID is an unsigned 32-bit integer (range 0–4294967295), packed big-endian. The byte length of the decoded binary must be a multiple of 4. Base64 is how the IdArray action delivers the blob over UPnP/SOAP.

Runs entirely in your browser — nothing is sent anywhere.
